## 2. CLI 工具进展
本周，各大 AI CLI 工具全面进入**“多智能体调度与底层系统级重构”**的深水区。
*   **架构大重构：** **Qwen Code** 和 **Pi** 大力推进向 Tauri 及全新 Harness v2 架构迁移；**OpenAI Codex** 继续以 Rust 重写核心，引入 gRPC 优化宿主隔离，并处于密集的 Alpha 高频迭代中。
*   **资源与上下文极限治理：** 长任务导致的资源枯竭成为通病。**OpenAI Codex** 和 **Pi** 频繁遭遇百 GB 级内存/磁盘 I/O 泄漏；几乎所有工具（如 **DeepSeek TUI, Gemini CLI**）都在重构上下文自动压缩（Auto-compaction）与 AST（抽象语法树）感知，以榨干每一滴 Token。
*   **系统级安全沙箱加固：** 赋予 Agent 过高系统权限带来的风险凸显。**Qwen Code** 和 **Gemini CLI** 紧急修复了 Shell 越权执行与 `rm -rf` 等破坏性操作漏洞；**Copilot CLI** 则致力于打通 MCP 协议的企业级鉴权。
*   **Windows / WSL 兼容性：** 跨平台体验依然严峻，**OpenAI Codex** 和 **Pi** 本周投入大量精力死磕 Windows/WSL 环境的路径解析与进程生命周期管理顽疾。

## 3. AI Agent 生态
以 **OpenClaw** 为代表的 Agent 编排框架本周经历了高强度的底层重构与 Bug 攻坚（日均处理 500+ Issues/PRs）。
*   **模型调用稳定性危机：** 第三方模型（如 `deepseek-v4-flash`）在接入复杂工作流时频繁“静默失败”，触发兜底回复，成为各大社区（如 OpenClaw + Telegram 组合）最破坏体验的痛点。
*   **内存与状态机隔离：** 针对长会话导致的 SQLite/OOM 崩溃，OpenClaw 引入了严格的内存信任分级机制和按记录划分的广播通道，防止 Agent 之间的上下文污染和状态死锁。
*   **异构多智能体通信：** 开发者强烈呼吁打破不同 CLI（如 Claude Code、Codex）之间的孤岛，出现了像 `Cowchat` 这样允许不同大厂 Agent 在本地安全对话的桥接工具。

## 4. 开源趋势
本周 GitHub Trending 反映出“AI 编码基建”的明确拐点：
*   **Agent 技能工程化：** 开发者不再满足于通用提示词。`reverse-skill`、`ECC` 等项目通过提供“即插即用”的特定工程技能包，让 CLI 拥有自动路由与执行复杂任务的能力。
*   **“无向量” RAG 与上下文压缩：** 针对大模型的上下文瓶颈，`Graphify` 提出无需向量库，纯靠 AST 解析代码库生成知识图谱；`Caveman` 甚至通过极端压缩 Prompt 语风，成功削减 65% 的 Token 消耗。
*   **Agent 记忆中枢：** 腾讯云等大厂入局，开源了团队级的 Agent 记忆中心（`TencentDB-Agent-Memory`），将历史对话转化为可复用的持久化资产。
*   **RL 框架全面转向 Agentic：** 强化学习（RL）生态彻底分化。以 `verl`、`TRL`、`AReaL` 为首的框架本周几乎放弃了通用算法的维护，将 100% 的工程精力投入到 LLM 的异构算力适配、显存墙突破（如 FP8 权重直传）以及长轮次 Agent 工具调用的对齐中。
