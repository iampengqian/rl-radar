## 2. Anthropic / Claude 内容精选

### 📰 News: 里程碑式的模型迭代与效能革命
**[Introducing Claude Opus 5](https://www.anthropic.com/news/claude-opus-5)**
- **发布日期**: 2026-07-25
- **核心内容提炼**:
  - **性能与定价的绝佳平衡**：Claude Opus 5 被定位为“深思熟虑且积极主动”的模型，其智能水平逼近 Anthropic 的前沿天花板（Claude Fable 5），但价格仅为后者的一半。这表明 Anthropic 正在通过极端的性价比策略抢占高阶企业应用市场。
  - **确立编码与知识工作新 SOTA**：在 Frontier-Bench v0.1 和 CursorBench 3.2 等针对软件工程和复杂问题解决的重磅评测中，Opus 5 超越了所有同级模型。在 CursorBench 满负荷状态下，其成绩仅落后 Fable 5 0.5%，但单位任务成本大幅降低。
  - **算力动态分配机制**：产品引入了“努力程度”设置。开发者和用户可以根据任务需求，在常规响应、深度推理 和极尽算力 之间灵活切换，以优化智能水平、响应速度和 Token 消耗。这标志着 LLM 产品正在从“单一性能输出”向“自适应算力调度”演进。
  - **产品线生态整合**：Opus 5 已成为高端订阅服务 Claude Max 的默认模型，并作为 Claude Pro 的最强可用模型，完成了对 C 端高净值用户和重度开发者的全面覆盖。
