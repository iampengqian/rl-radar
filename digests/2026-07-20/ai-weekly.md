## 2. CLI 工具进展

各大 AI CLI 工具本周跨越了单行补全，全面进入**系统级沙箱隔离、子代理调度与跨端协同（ACP 协议）**的深水区：

- **Claude Code**：本周经历了底层运行时的质变（迁移至 Rust Bun），加速修补多 Agent 下的 Filesystem 死锁问题，并支持手机端远程接管桌面会话。但社区对静默消耗 Token 导致的高额账单（甚至单次扣费千美元）抱怨不断。
- **OpenAI Codex**：Windows 平台兼容性（ARM 崩溃、HID 死锁）依然是最大痛点。底层正大规模重构 MCP 并发机制，并于本周将 Codex 上下文窗口从 372k 悄悄下调至 272k，被视为算力成本妥协的信号。
- **Gemini CLI**：发力重构系统级安全网关（Seatbelt 沙箱），阻断 `$VAR` 路径变量绕过，并引入 AST 感知文件读取以大幅降低 Token 噪音。
- **Qwen Code / Kimi Code**：国产 CLI 力量崛起。Kimi CLI 成为 GitHub 热榜常客；Qwen Code 落地 `qwen serve` 守护进程，支持多工作区隔离，并大力推进 Web Shell IDE 化。
- **通用痛点**：Windows 虚拟化与终端 TUI 渲染崩溃是几乎所有 CLI 工具的灾难区；开发者强烈要求建立硬性的执行次数与金额阻断机制，防止 Agent 失控。

## 3. AI Agent 生态

以 OpenClaw 为代表的个人/团队智能体框架本周保持极高活跃度（日均处理 PR 近 500 个）：

- **OpenClaw 重磅更新**：发布 v2026.7.2-beta.3，引入**远程编码会话**机制，允许在云端 Worker 运行控制 UI，并在宿主机终端直接无缝接管 Codex、Claude 和 Pi 会话。
- **安全信任边界**：社区热议基于来源的“记忆信任标签”，以防范恶意网页或三方插件带来的“Agent 记忆投毒”攻击。引入了密钥掩码机制，允许 Agent 调用 API 但阻断其窃取原始 Key。
- **底层设施加固**：本周合并了大量针对网关稳定性、SQLite 状态迁移与正则表达式 ReDoS 防护的修复 PR。Linux/Windows 原生桌面客户端的呼声达到顶峰。
- **RL 训练框架演进**：强化学习生态全面转向 Agentic RL（多轮工具调用）。verl、TRL 等框架死磕全异步 PPO 架构与万卡集群下的通信墙压榨（FP8 传输、增量权重同步）。

## 4. 开源趋势

本周 GitHub Trending 与社区搜索呈现出三大高度聚焦的技术方向：

1. **Agentic Skills 与安全护栏爆发**：以 `mattpocock/skills`、`hallmark` 为代表的技能包狂飙突起。开发者正致力于为 Agent 提供专业上下文（如防 AI 同质化设计、市场营销等）。同时，用 Rust 编写的危险命令拦截器 `destructive_command_guard` 成为刚需基建。
2. **上下文工程重构**：基于知识图谱的代码检索工具（如 `graphify`）取代了传统 RAG，为 CLI 提供全局架构视野，极大降低 Token 消耗。
3. **极致端侧推理**：`airllm` 支持单张 4GB 显卡跑 70B 模型；基于纯 WASM 驱动的本地 LLM 推理管理器（如 `Goku`）崭露头角，标志着边缘计算与隐私优先重回主线。
